# Установка Nightfall Survivors на RG40XX H

Сборка предназначена для **Anbernic RG40XX H, muOS, Linux ARM64**. На RG40XX H / muOS 2601.0 проверены физический видеовывод, программная подача событий контроллера и цифровой аудиовыход версии 0.1.2. Долгие аппаратные сценарии ещё не завершены. Актуальный статус — в [отчёте](HARDWARE-TEST.md).

## Что скачать

В GitHub Releases скачайте файл **`nightfall-<версия>-muos.zip`**. Это готовый комплект игры. Файл без расширения `nightfall-<версия>-aarch64` и `latest-aarch64.txt` нужны апдейтеру; устанавливать их вручную вместо архива не требуется.

## Установка

1. Установите PortMaster средствами вашей muOS: загрузчик использует его настройки контроллера и окружения.
2. Выключите приставку и откройте SD-карту на компьютере либо перенесите файлы через уже настроенный доступ к устройству.
3. Распакуйте архив. Поместите `Nightfall Survivors.sh` и папку `nightfall` рядом в каталог портов, доступный из меню muOS. Инструкция `INSTALL-RU.md` в корне архива — для чтения.
4. Если ваша muOS хранит запускающие скрипты отдельно: скрипт положите в свой каталог `ROMS/PORTS`, а данные — в `/mnt/mmc/ports/nightfall` или `/mnt/sdcard/ports/nightfall` на приставке. Выбор точного каталога зависит от SD-карты и версии muOS.
5. Откройте игру в меню портов. Если muOS требует выбора ядра для скрипта, назначьте External/Ports.

Содержимое каталога порта:

```text
Nightfall Survivors.sh
nightfall/
  nightfall.aarch64
  VERSION
  update.sh
  update-url.txt
  README.md
  DESIGN.md
  screenshot.png
  docs/
  licenses/
```

Сохраняйте структуру и регистр имён. При запуске непосредственно из оболочки скрипту и бинарнику нужны права исполнения. Обычное копирование на FAT/exFAT может не сохранять Unix-права; фактическое поведение зависит от монтирования карты в muOS.

## Переход с раннего прототипа

При переходе с 0.1.0/0.1.1 установите полный архив 0.1.2: исправления касаются запускающего скрипта, графики и звука. Сохраните существующую папку `nightfall/save`. Сам апдейтер заменяет только бинарник.

## Первый запуск и управление

Выберите **SOLO SURVIVAL**. Левый стик или крестовина двигают мага; атаки происходят автоматически. Собирайте зелёные самоцветы, выбирайте улучшения и переживите пять минут. Для победы нужно также победить Стража, появляющегося на четвёртой минуте.

- A — подтвердить; B — назад; Start — меню.
- В меню: вверх/вниз — выбрать пункт.
- В одиночной игре меню и выбор улучшения останавливают бой.
- В сетевой игре бой продолжается. Живой союзник воскрешает павшего, находясь рядом три секунды.

В 0.1.2 проверена обработка SDL-раскладки PortMaster для контроллера Deeplay-keys на RG40XX H программной подачей событий через evdev. Физическое состояние самих переключателей программно не проверяется.

## Совместная игра

1. Установите одну версию игры всем участникам, подключитесь к одной Wi-Fi/локальной сети.
2. Ведущий выбирает **HOST CO-OP** и сообщает свой IPv4 из строки над полем.
3. Остальные выбирают **JOIN CO-OP**. Вверх/вниз меняют число, влево/вправо выбирают часть IP. A на последней части или Start подключают к ведущему.
4. На компьютере ведущего разрешите входящий **TCP 40440**. Игра поддерживает до четырёх участников, включая ведущего.

При нескольких сетевых интерфейсах проверьте адрес нужной сети. Для удалённой игры ведущий должен быть доступен по IPv4; поиск комнат и обход NAT пока отсутствуют. Готовых клиентов Windows/Android/iOS нет; нативные macOS и Linux ARM64 используют один протокол. К Vampire Survivors эта игра не подключается.

## Автоматические обновления

Запускайте игру через `Nightfall Survivors.sh`: он проверяет новый релиз перед стартом. При недоступной сети открывается установленная копия. Новый бинарник проверяется по SHA-256; при неудачном старте восстанавливается предыдущий.

- Проверка релиза: не более восьми секунд; загрузка: не более минуты.
- Настройки и сохранённый IP: `nightfall/save/settings.txt`.
- Лог: `nightfall/log.txt`.
- Адрес канала: `nightfall/update-url.txt`; при сборке он указывает на фактический репозиторий релиза.
- Чтобы отключить обновления, создайте пустой `nightfall/updates.disabled`.
- Если версия не запустилась, она запоминается в `nightfall/failed-version`. Удаляйте этот файл только для осознанной повторной попытки.

Обновляется исполняемый файл игры. Для обновления самого загрузчика и документации распакуйте новый полный архив, сохранив каталог `save`. Сетевые партии и состояние текущего забега между запусками не сохраняются.

## Если игра не открылась

Проверьте структуру папок и прочитайте `nightfall/log.txt`. Для диагностики нужны фактическая версия muOS, путь к установленной игре и сообщения из лога. Ошибки загрузчика библиотек, видеодрайвера или контроллера требуют проверки на устройстве; успешная сборка ARM64 в контейнере не подтверждает аппаратную совместимость.
