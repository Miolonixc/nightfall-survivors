# Nightfall Survivors 0.1.1

Готовый комплект игрового прототипа для **Anbernic RG40XX H / muOS** с документацией и планом развития.

## Скачать

- **`nightfall-0.1.1-muos.zip`** — игра для установки на приставку.
- **`INSTALL-RU.md`** — подробная инструкция на русском.
- **`nightfall-0.1.1-docs.zip`** — документация, игровой дизайн, архитектура, план развития, результаты проверок и порядок следующих релизов.
- `nightfall-0.1.1-aarch64` и `latest-aarch64.txt` — файлы автоматического обновления; вручную устанавливать их вместо полного ZIP не нужно.

## Установить

1. Установить PortMaster средствами muOS.
2. Распаковать полный ZIP: `Nightfall Survivors.sh` и папка `nightfall` должны лежать рядом в каталоге портов, который видит меню muOS. Для раздельной схемы скрипт и данные размещаются по инструкции `INSTALL-RU.md`.
3. Запустить **Nightfall Survivors** из меню портов. A — подтвердить, B — назад, Start — меню; движение — левый стик или крестовина. Атаки автоматические.
4. Для кооператива один игрок выбирает **HOST CO-OP**, остальные вводят его IPv4 через **JOIN CO-OP**. До четырёх участников, одинаковая версия, TCP 40440. Первая цель — общая Wi-Fi/локальная сеть.

Запуск через скрипт проверяет обновления до старта игры. При недоступном интернете запускается установленная копия; при неудачном старте обновлённой версии предусмотрен откат. В этом установочном архиве адрес апдейтера указывает на фактический репозиторий выпуска.

## Изменения

Добавлены полная русская инструкция, план развития и релизов, архитектура и описание сети, результаты проверок, журнал изменений. Все документы и игровой кадр теперь входят в комплект установки. Настроено включение инструкции и отдельного архива документов в будущие релизы GitHub Actions.

Игровые правила сохранены: пятиминутное выживание, три типа обычных врагов и босс, автоатаки, опыт, шесть усилений, совместное выживание и воскрешение союзников.

## Проверки и ограничения

Проверены сборка и автоматические сценарии macOS и Linux ARM64: бой, прокачка, 330 секунд симуляции, воскрешение и босс, сетевые пакеты, четыре игровых процесса, навигация контроллером, обновления и откат. Ранее отдельно проверена сессия macOS ↔ Linux ARM64.

**Физическая RG40XX H ещё не проверена**: дисплей, звук, реальные кнопки, пути muOS и производительность остаются следующим этапом. Готовых клиентов Windows/Android/iOS, поиска комнат и обхода NAT пока нет. Игра самостоятельная; к Vampire Survivors не подключается.
