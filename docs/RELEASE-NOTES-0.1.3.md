# Nightfall Survivors 0.1.3 — различимость в толпе

Враги получили тёмные контуры, разные силуэты и более отчётливые лица. Отрисовка по глубине сохраняет понятный порядок перекрытий. Земля и опыт приглушены, белые снаряды выделены тёмным краем. Герой имеет светлую окантовку, не исчезает при получении урона и остаётся поверх мелких эффектов. Боевые правила сохранены.

На RG40XX H / muOS 2601.0 Jacaranda проверен настоящий экран 640 × 480. Короткая сцена с 240 врагами и до 31 снаряда: **59,56 FPS**, p95 **16,92 мс**, p99 **17,12 мс** за 20 секунд. Пройдены проверки симуляции, сетевого кооператива, интерфейса и обновлений на macOS и Linux ARM64.

Скачайте `nightfall-0.1.3-muos.zip` и следуйте `INSTALL-RU.md`, сохранив папку `nightfall/save`. С версии 0.1.2 достаточно встроенного обновления при наличии доступа к GitHub. С 0.1.0/0.1.1 нужен полный комплект с исправленным ярлыком. На тестовой приставке ранее наблюдалась проблема DNS, поэтому эта версия установлена напрямую; системные сетевые настройки не менялись.

Обычный запуск: **PORTS → Nightfall Survivors**. A — выбор, B — назад, Start — меню, левый стик или крестовина — движение. Автоатаки работают постоянно.

Архив документации содержит инструкции, архитектуру, планы развития, лицензии и результаты аппаратных проверок. Исходники шрифтов и воспроизводимый генератор атласов сохранены в репозитории.
