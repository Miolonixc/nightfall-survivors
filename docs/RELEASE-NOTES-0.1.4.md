# Nightfall Survivors 0.1.4 — тёмное пиксельное фэнтези

Полностью перерисованы маги четырёх команд, мертвецы, крылатые твари, тяжёлые стражи и Хранитель. Добавлены анимация, складки плащей, броня, посохи, каменные кресты, надгробия, дорожки, горящие жаровни и тёплый свет. Улучшения получили собственные значки; полосы и панели — золотые детали. Сохранены читаемость в толпе и стилизованные шрифты.

Графика встроена в один атлас: **50 кадров**, собственные исходники рисунков и воспроизводимый генератор сохранены в репозитории. Бинарное автообновление включает все новые изображения. Исправлено повторное ожидание кадра при VSync.

На **RG40XX H / muOS 2601.0 Jacaranda** с открытым контроллером: **59,83 FPS при 240 врагах**, p95 **16,83 мс**, p99 **16,96 мс** за 20 секунд. Обычный бой: **59,34 FPS** за 6 секунд. Это короткие проверки, не полный тепловой прогон. Снимки физического экрана и подробные метрики включены в документацию. Проверки симуляции, кооператива, интерфейса и апдейтера пройдены на macOS и ARM64.

Скачайте `nightfall-0.1.4-muos.zip` и следуйте `INSTALL-RU.md`, сохранив папку `nightfall/save`. С 0.1.2/0.1.3 доступно встроенное обновление при рабочем доступе к GitHub. С 0.1.0/0.1.1 нужен полный комплект с исправленным ярлыком. На тестовой приставке версия установлена напрямую; скачивание через внешний DNS повторно не проверялось.

Обычный запуск: **PORTS → Nightfall Survivors**. A — выбор, B — назад, Start — меню, левый стик или крестовина — движение. Атаки автоматические.
