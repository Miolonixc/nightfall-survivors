# Проверки и ограничения

Записано 20 октября 2026 года для семейства прототипов 0.1.x. Результаты ниже отделяют проверку программы от проверки настоящей приставки.

## Уже проверено

- Сборка C++17 на macOS и в Linux ARM64 с предупреждениями, трактуемыми как ошибки в ARM64-рецепте.
- Движение и границы арены, автоатака, выпадение/подбор опыта, выбор усиления, смерть группы, воскрешение, появление босса и условие победы.
- 330 секунд симуляционной нагрузки с контролем лимитов сущностей; это не измерение FPS на устройстве.
- Сериализация максимально заполненного снимка, отклонение усечённых пакетов и NaN.
- Четыре отдельных игровых процесса через настоящие TCP-сокеты: отдельные места игроков, снимки, плохие пакеты и отключение ведущего.
- Совместная сессия ведущего macOS и клиента Linux ARM64 в Docker.
- Навигация меню событиями SDL-контроллера: соло, пауза, продолжение, справка, ввод IP, создание комнаты, выход.
- Настоящее окно macOS и визуальная проверка игрового кадра; `screenshot.png` получен из отрисовки игры.
- Апдейтер: установка, проверка HTTPS и SHA-256, отказ от старой версии, офлайн-запуск, оставшийся PID-lock, откат раннего сбоя, блокировка неудачной версии.
- Реальное скачивание 0.1.0 из GitHub Releases, проверка SHA-256 и установка в изолированный проверочный каталог.
- GitHub Actions для исходного релиза 0.1.0: задания macOS и Linux ARM64 завершились успешно.

## Как повторить

На macOS/Linux с SDL2: `make test`. В закреплённом ARM64-контейнере: `bash packaging/build-arm64.sh`. Сценарий ARM64 сам запускает симуляционные, интерфейсные, сетевые проверки и проверки обновления.

`--demo --frames 800 --capture frame.bmp` запускает игровой автопилот и сохраняет кадр. `--headless` включает SDL dummy-драйверы: он подходит для автоматических сценариев, но не проверяет настоящий дисплей или звук.

## Аппаратная проверка 0.1.2

На RG40XX H / muOS 2601.0 подтверждены физический видеовывод Mali/OpenGL ES 2, события контроллера через evdev (меню, запуск, стик, крестовина, пауза, возврат, ввод IP, выход), цифровой выход звука 44,1 кГц stereo и короткая стресс-проба на 240 врагов. Результаты, ограничения и исходные JSON — в [аппаратном отчёте](HARDWARE-TEST.md).

## Осталось проверить

Долгий тепловой прогон полного забега, сон/возобновление, длительная утечка памяти, сетевая партия с несколькими клиентами на самой приставке и полный цикл загрузки обновления при рабочем внешнем DNS. Цифровая запись аудиовыхода не заменяет акустическую проверку динамика; обработка событий ввода не проверяет механические переключатели.

KNULLI, клиенты Windows/Android/iOS и игра через внешнюю интернет-сеть не проверены.
